Available Tools

1. fetch_ec2_metrics_for_alarm_instances

Monitors EC2 instances by fetching CloudWatch alarm data and relevant metrics.

  • Input: alarm_state (default: "ALARM"), period (default: 300)
  • Output: Dictionary mapping instance IDs to metrics
  • Metrics gathered: CPUUtilization, NetworkIn, NetworkOut, DiskReadOps, DiskWriteOps, StatusCheckFailed

2. diagnose_ec2_and_health

Provides detailed diagnostic information about EC2 instances and AWS Health events.

  • Input: instance_ids (single ID or list), event_status (default: "open")
  • Output: Dictionary with instance status details and health events
  • Checks: Instance status, system status, instance events

3. create_jira_issue

Creates a JIRA ticket with incident details for resolution tracking.

  • Input: summary, description, project_key (default: "AIRT"), issue_type (default: "Task"), assignee (optional)
  • Output: JIRA API response with ticket details
